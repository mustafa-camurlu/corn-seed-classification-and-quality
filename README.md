# Misir Tohumlarinda Cesit ve Kalite Siniflandirmasi

Bu proje, misir tohumlarinin optik fotograflari uzerinden cesit dogrulugunu ve kusur/kalite durumunu derin ogrenme yontemleriyle tespit etmeyi amaclar.

## 1. Veri Setleri
* Veri Seti 1 (Cesit Siniflandirmasi): https://www.kaggle.com/datasets/muratkokludataset/corn-3-classes-image-dataset
* Veri Seti 2 (Kusur ve Kalite Tespiti): https://www.kaggle.com/datasets/aravind1829/seed-quality-and-defect-image-dataset-corn

## 2. Literatur Ozeti
Morfometrik analizler ve transfer ogrenme (ResNet, SqueezeNet vb.) yontemleriyle misir tohumlarinda %97-98 bandinda basarim elde edildigi gorulmustur.

## 3. Aday Modeller
* Baseline CNN
* ResNet50
* MobileNetV2
* EfficientNet-B0
